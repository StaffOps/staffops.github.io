# AGENTS.md

Guide for AI agents working in this repo: the StaffOps public portal at <https://staffops.github.io/>,
an MkDocs Material site with one page per product.

## Branches

| Branch | Use |
|---|---|
| `main` | Source. Every push deploys the site. Commits have landed directly on it so far (no pull requests) |
| `gh-pages` | Generated by the deploy workflow and shared with the sub-sites other repos publish (for example `/helm-charts/`, `/grafana-plugins/`). Never edit by hand |

## Commands

```bash
docker run --rm -v "$PWD:/docs" -w /docs squidfunk/mkdocs-material:latest build --strict
docker run --rm -p 8000:8000 -v "$PWD:/docs" squidfunk/mkdocs-material:latest   # http://localhost:8000
```

CI (`.github/workflows/deploy.yml`) runs `mkdocs build` (not strict) and publishes `site/` to
`gh-pages` with `keep_files: true`.

## Rules

- **English only**: pages, nav titles, CHANGELOG and commits.
- **Conventional Commits** (`docs(products): ...`, `fix(ci): ...`).
- **CHANGELOG** `[Unreleased]` changes with every user-visible page change. Update
  [docs/handoff.md](docs/handoff.md) when you stop with work in flight.
- **A product page summarises; the product's own docs are the source.** Keep install commands and
  versions in step with the product repo and link to its docs.
- **Secrets are never committed**; the deploy uses only `GITHUB_TOKEN`.

## Pitfalls

| Pitfall | What to do |
|---|---|
| A clean deploy wipes the sub-sites other repos publish to `gh-pages` | Keep `keep_files: true` in the workflow; never deploy with `--clean` |
| The home page uses `template: home.html` from `docs/overrides`, which Backstage TechDocs strips | Keep content that must render in Backstage on plain Markdown pages |
